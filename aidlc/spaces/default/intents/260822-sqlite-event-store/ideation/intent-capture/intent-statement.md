# インテントステートメント: SQLite対応EventStoreとバックエンドfeature分割

## 問題ステートメント

- event-store-adapter-rs に SQLite 対応の EventStore 実装を追加し、どのイベントストアを使うかを feature で選択可能にする（3種類分）。[desc]
- 中心的な課題は CLI ツールでの利用である。クラウドサービスへの接続を前提としない軽量なイベントストアが必要とされている。[Q1]
- feature 分割の対象は `dynamodb` / `bigtable` / `sqlite` の3つであり、Memory バックエンドは常時有効のままとする。[Q9]
- デフォルト feature は設けず、利用者が必ず明示的にバックエンドを選択する構成とする。[Q3]

## ターゲット顧客
